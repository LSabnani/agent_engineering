# my-work/

Your own attempts at each class live here — gitignored except this file, so
`git pull`/`git merge` from upstream never conflicts with your in-progress
work.

Structure, one folder per edition/book and class:

```
my-work/
├── book-1/                  # Claude edition, Book 1
│   ├── class-04/
│   ├── class-05/
│   └── ...
├── book-2/                  # Claude edition, Book 2
│   └── ...
├── gemini-book-1/            # Gemini edition, Book 1
│   ├── class-02/
│   ├── class-03/
│   └── ...
```

For the Claude edition, see `../HOW-TO-WORK-A-CLASS.md` for the full
workflow. For the Gemini edition, see
`../manuscript/Gemini/course/HOW-TO-WORK-A-CLASS.md` — the same pattern,
adapted for Antigravity and the Gemini course's own file layout.

Short version, either edition: copy the *previous* class's completed golden
solution in here as your starting point, then follow that class's
`BUILD.md` — don't open the reference `golden-solution/` (Gemini) or
`class-NN-.../` (Claude) folder until you've made your own attempt, since
that folder already contains the finished answer.
